# 서울의 2023~2024년 일별 기온 변화 분석

기상청에서 제공하는 서울의 일별 기온 데이터를 이용해 계절적인 흐름과 연도별 차이, 하루 사이의 급격한 변화를 분석한 프로젝트입니다. 단순히 그래프를 그리는 데서 끝내지 않고, 그래프에서 확인한 사실과 가능한 해석을 구분해 정리했습니다.

전체 분석 과정과 그래프 해석은 **[분석 리포트 보기](REPORT.md)**에서 확인할 수 있습니다.

## 분석 질문

1. 2023년과 2024년의 월별 평균기온은 얼마나 달랐는가?
2. 일평균기온이 전날보다 가장 크게 상승하거나 하락한 날은 언제인가?
3. 7일 이동평균을 적용하면 일별 변동에 가려진 흐름이 어떻게 나타나는가?

## 데이터

- 출처: [기상청 기상자료개방포털 기온분석](https://data.kma.go.kr/stcs/grnd/grndTaList.do?pgmNo=70)
- 관측 지점: 서울(108)
- 기간: 2023-01-01 ~ 2024-12-31
- 데이터 수: 731개
- 컬럼: 날짜, 지점, 평균기온, 최저기온, 최고기온
- 점검 결과: 결측치, 누락 날짜, 중복 날짜 모두 0개

원본 CSV는 기상청 페이지에서 직접 내려받았으며 CP949 인코딩으로 저장되어 있습니다. 자료 이용 정책의 개별 표시를 확인하지 못해 원본 파일은 저장소에 포함하지 않고, [data/README.md](data/README.md)에 재수집 방법을 기록했습니다.

## 분석 방법

- 7일 이동평균으로 하루 단위 변동을 완화하고 전체 흐름 확인
- 연도별 월평균을 계산해 같은 달의 기온 차이 비교
- 전일 대비 평균기온 차이를 계산해 급격한 변화 시점 확인
- IQR 기준으로 통계적으로 큰 변화를 찾되, 실제 날씨 변화일 수 있으므로 삭제하지 않음

## 주요 결과

- 2024년 연평균기온은 14.88℃로 2023년의 14.11℃보다 0.77℃ 높았습니다.
- 가장 큰 하락은 2023년 1월 24일의 -13.9℃, 가장 큰 상승은 2023년 3월 14일의 +6.3℃였습니다.
- IQR 기준으로 통계적으로 큰 변화는 22일이었으며, 하락 21일과 상승 1일이었습니다.
- 7일 이동평균은 겨울의 저점과 여름의 고점, 계절이 바뀌는 흐름을 일별 값보다 분명하게 보여주었습니다.
- 주 단위로 다시 집계하면 큰 변화 5주 중 상승 3주, 하락 2주로 나타나 일 단위의 방향성이 유지되지 않았습니다.

## 실행 방법

Python 3.10 이상이 필요합니다.

```bash
git clone https://github.com/yak7297/p3-1.git
cd p3-1
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

기상청 기온분석 페이지에서 다음 조건으로 CSV를 내려받습니다.

- 자료구분: 일
- 자료형태: 기본
- 기간: 20230101 ~ 20241231
- 지역/지점: 서울(108)

다운로드한 파일을 `data/seoul_2023_2024.csv`로 저장한 후 실행합니다.

```bash
python analysis.py
```

실행이 끝나면 데이터 품질 점검과 주요 분석 결과가 터미널에 표시되고, `images` 폴더의 그래프 4개가 생성됩니다.

## 분석의 한계

분석 기간이 2년이므로 장기적인 기후변화 추세를 판단하기 어렵습니다. 또한 서울 관측소 한 곳의 자료만 사용했기 때문에 서울 전체 지역의 차이를 반영하지 못합니다. 급격한 기온 변화의 원인을 확인하려면 기압, 풍향, 기상특보 같은 추가 자료가 필요합니다.

## AI 사용

프로젝트 구조, 데이터 점검 코드, 시각화와 문장 초안 작성에 AI의 도움을 받았습니다. 계산 결과를 원본 데이터와 코드 실행 결과로 다시 확인했으며, 자세한 사용 작업과 검증 방법은 [REPORT.md의 AI 사용 로그](REPORT.md#8-ai-사용-로그)에 기록했습니다.
